# Project Reflection - Three.js Experiment
### MART 441 | Ethan Gibson  


## 1. Conceptual Understanding

Figuring out the correct way to orient objects is probably one of the weirder things to work through in Three.js. The other thing I realized is that there is a lot of weirdness with referencing libraries when you download them locally; CDN-ing them is miles easier. It was different from 2D work because instead of only worrying about two dimensions, I'm able to orient things in a completely different way, which opens so much more room for creativity.


## 2. Technical Challenges

The hardest thing for me was going through the process and actually understanding how to structure a Three.js project. I ran into a lot of weird syntax errors and load order issues along the way. I worked through it by getting help from Claude.ai with understanding how to format the page, then went through and added the shapes and objects I wanted myself. I also asked it to help me learn how to implement a constant rotation feature.

At one point I got curious about just how much Three.js is capable of and asked Claude to create a rendition of my project. His made mine feel like Eric Cartman to Pablo Picasso. I guess when it comes to geometric shapes in a 3D environment, AI has that on lock.


## 3. Design & Intent

I wanted to try and create something resembling the sky, and ended up making a blue sphere to act as if the sky was captured above the boat. I wanted the flat shape underneath to look like water at first, but after thinking through how to actually pull that off I decided to make it look like the boat was sitting on a slab of concrete instead. Admittedly there wasn't too much overthinking involved; being this close to graduation, a lot of projects have been like that. I can't lie.


## 4. Growth & Iteration

I might actually use Three.js in the future. I've done work in Blender, and I can easily see ways for people to interact with 3D models I've made by bringing them into the web with this. This may end up being something I use heavily in projects going forward.
